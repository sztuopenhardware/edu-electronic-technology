# 《模拟电子技术A》交互式 SPICE 教学仿真平台

基于 **Ngspice WebAssembly (`eecircuit-engine`)** 构建的纯前端《模拟电子技术A》（课程编号 `SG00383`）全章节交互式电路仿真与实验演示网站。无需任何后端服务器，所有 SPICE 电路矩阵求解（`.tran` 瞬态、`.ac` 频响波特图、`.dc` 伏安/传输扫描）均在浏览器本地毫秒级实时运行，可直接部署至 **GitHub Pages**。

---

## 核心特性

1. **按章节级联下拉菜单导航**：顶部导航栏提供【选择章节】与【本章仿真案例】双联下拉菜单（并附全大纲 35+ 知识点 / 47 个交互案例速览矩阵），支持 URL Hash (`#case=...`) 课堂直达分享。
2. **教学大纲 100% 全覆盖**：
   - **第1章 绪论**：奇次谐波信号合成与 FFT 频谱、电压放大电路四端等效模型（$A_{vo}, R_i, R_o$）
   - **第2章 运算放大器**：传输特性限幅、反相比例（虚地验证）、同相比例与跟随器、加减运算、微积分运算、**AI项目实践：三运放仪用放大器心电图 (ECG) 抗 50Hz 工频干扰前端**
   - **第3章 二极管及其基本电路**：硅/锗/肖特基/LED 伏安曲线、双向限幅与底部钳位、齐纳稳压管反向击穿稳压、**AI项目实践：手机充电器全波整流桥**
   - **第4章 场效应三极管及其放大电路**：NMOS 输出特性族、共源极放大、共漏/共栅组态对比、JFET 自给偏压、**AI项目实践：MOSFET 大信号开关 LED PWM 调光台灯**
   - **第5章 双极结型三极管 (BJT) 及放大电路**：BJT 三区输出特性族、共射 Q 点与截止/饱和失真动态复现、分压射极偏置结温漂移（$0^\circ\text{C}\sim 100^\circ\text{C}$）稳定对比、共集/共基组态、CE-CC 多级放大、**AI项目实践：楼道声控延时照明灯**
   - **第6章 频率响应**：一阶 RC 高/低通波特图、单管 BJT 全频段波特图（密勒效应 $C_\mu$）、MOS 共源与 Cascode 宽带频响对比
   - **第7章 集成运算放大电路**：基本镜像/微电流/Cascode 电流源对比、长尾与恒流源差分放大（CMRR）、OCL 乙类交越失真与甲乙类消除、运放过流限流保护电路
   - **第8章 反馈放大器**：四种负反馈组态（稳压 vs 稳流）、负反馈减小失真与展宽频带 $(1+AF)$ 对比、深度负反馈 $A_f \approx 1/F$ 估算、三级极点自激振铃与主极点电容相位补偿
   - **第9章 信号处理与信号产生电路**：二阶 Sallen-Key 低通/高通/带通/双T带阻有源滤波器、**AI项目实践：RC 文氏电桥正弦波起振与稳幅**、过零 vs 正反馈迟滞比较器抗噪、方波-三角波函数发生器
   - **第10章 直流稳压电源**：单相桥式整流电容滤波与浪涌电流、串联反馈式线性稳压电路、三端集成稳压器（7805 / LM317 全链路可调电源）
   - **课内实践（必做实验一 ~ 实验六）**：虚拟信号源/万用表/示波器联调、比例求和五大子项、单管静态 Q 点电位器调试、两步分压换算法测 $R_i / R_o$、射极跟随器实验、三角波 X-Y 滞回比较器实验
3. **五大虚拟测试仪器视图 + 在线 SPICE 网表编辑器**：
   - 时域多通道数字示波器（`.tran`）
   - 对数频率幅频/相频波特图仪（`.ac`，自动测算 $-3\text{ dB}$ 截止频率 $f_L, f_H$ 与相位裕度）
   - 直流特性曲线图示仪（`.dc`，支持多阶梯曲线族）
   - X-Y 传输特性与迟滞回环模式
   - Hann 窗 FFT 谐波频谱与总谐波失真（THD %）实时分析仪
   - 支持展开查看或直接修改底层 Ngspice 网表并一键重算

## 本地运行与构建

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器
npm run dev

# 3. 构建静态生产包（输出至 dist/ 目录，已配置相对路径 base: './'）
npm run build
```

## 发布到 GitHub Pages 指南

本项目已内置：
- `vite.config.ts` 相对路径配置 `base: './'`（自适应任意仓库子路径 `https://<用户名>.github.io/<仓库名>/`）
- `public/.nojekyll` 静态资源直通标记
- `.github/workflows/deploy.yml` 自动化部署工作流

### 一键自动部署步骤

1. 在 GitHub 新建仓库并将本项目代码推送到 `main` 分支：
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Analog Electronics Ngspice WASM Lab"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<你的仓库名>.git
   git push -u origin main
   ```
2. 打开 GitHub 仓库页面 → **Settings** → **Pages**。
3. 在 **Build and deployment** → **Source** 下拉框中选择 **GitHub Actions**。
4. Actions 工作流将自动完成构建并发布网站，约 1 分钟后即可通过生成的 GitHub Pages 网址在线访问全部仿真案例。
